# DAYSTATE Website

Website von DAYSTATE · Rituales en gotas (Kolumbien), Spanisch (es-CO) mit englischer Version unter `/en/`.

## Stand

Sicherung der ChatGPT-Version vom 07.11.2026 (live unter `daystate-your-moment.ivybears-8790.chatgpt.site`), unverändert übernommen.

## Ordner

- `site/` – die Website: HTML-Seiten, `style.css`, `app.js`, Bilder, Logos, Schriften
- `docs/` – Texte aller Seiten (`content.md`), Screenshots, Nachbau-Anleitung

## Shopify

`app.js` nutzt die Shopify Storefront API (Warenkorb → Shopify-Checkout). Die Zugangsdaten (`shopify.domain`, `shopify.publicAccessToken`) sind noch leer, darum ist der Checkout noch nicht aktiv.

## Bekannte Altlasten aus der Kopie

Dateien wie `bundles?ritual=beauty.html` oder `proximamente?producto=MOVE.html` sind Kopien derselben Seite mit URL-Parametern. Sie werden beim Aufräumen durch je eine Seite ersetzt.
